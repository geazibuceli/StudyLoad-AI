TRANSPARENCY

Privacy and responsible use

Private text, local storage

Tasks are stored in this browser. Task and course names remain here; only structural fields such as dates, hours, progress, and priority are sent transiently to the current analysis server.

Minimal prediction inputs

The model uses counts, dates, remaining hours, priorities, and capacity. Private text is replaced with neutral placeholders before analysis.

Not a medical tool

StudyBalance does not diagnose, screen for, or treat stress, burnout, anxiety, depression, or any other health condition. Seek qualified support when you need it.

Prototype limitations

The model is trained on synthetic schedules. Its output demonstrates a technical approach and must be validated with consented, representative data before institutional use.

MODEL TRANSPARENCY

How the workload score works

A schedule-only index

The model uses counts, deadlines, remaining hours, priorities, progress, and the study capacity you enter. It does not use task names or infer a health state.

From probabilities to 0–100

The score is rounded from 50 times the moderate-demand probability plus 100 times the high-demand probability. The largest class probability sets the displayed level.

Confidence has limits

Confidence is the model probability for the selected class, not a guarantee. The model was trained and checked only on synthetic schedules, so the score is not a validated student scale.
